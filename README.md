# 🐺 Волк на грядке

Мамин рукописный блокнот, переведённый в печатный вид: огород и заготовки.
Крупный шрифт, большие кнопки, поиск по всем записям.

## Что где лежит

```
волк на грядке/
├── index.html      каркас страницы
├── styles.css      оформление (цвета, размеры, ромашки, лапы)
├── app.js          логика: разделы, поиск, просмотр фото
├── data/
│   └── data.js     ВСЕ ЗАПИСИ. Правится только этот файл
├── photos/         фотографии страниц блокнота (IMG_xxxx.jpeg)
└── assets/         картинки волка, ромашки, лапы
```

## Как открыть

- **В интернете:** https://lera-rawlick.github.io/Wolk-na-gruadke/ — открывается с телефона,
  можно добавить на домашний экран.
- **На компьютере:** двойным кликом по `index.html`, интернет не нужен.

## Как править прямо в браузере

Проще всего — **с самого сайта**:

1. Открыть нужную запись.
2. Внизу неё нажать зелёную кнопку **«✏️ Исправить эту запись»**.
3. Откроется редактор GitHub. Скопировать подсказку с карточки (`id: 'hrenovina'`),
   нажать Ctrl+F / ⌘F и вставить — курсор встанет на эту запись.
4. Поменять текст, внизу нажать **Commit changes**.
5. Через минуту сайт обновится сам.

Та же инструкция есть на самом сайте: ссылка «Как исправить или дописать запись»
на главной, или адрес `#/help`.

Кнопка ведёт по адресу из поля `editUrl` в начале `data/data.js` — если репозиторий
переедет, поменять надо только там.

## Как изменить или добавить запись

Открыть `data/data.js` в любом текстовом редакторе. Каждая запись выглядит так:

```js
{
  id: 'ketchup',                  // короткое уникальное имя латиницей
  section: 'z-sousy',             // в каком разделе показывать
  title: 'Домашний кетчуп на зиму',
  tags: ['кетчуп', 'помидоры'],   // слова, по которым запись найдётся в поиске
  blocks: [
    { h: 'Состав', items: ['Помидоры — 2 кг.', 'Яблоки — 250 г.'] },
    { text: 'Обычный абзац текста' }
  ],
  notes: [ { type: 'info', text: 'Пометка' } ],   // type: 'info' или 'warn'
  photos: ['IMG_2512.jpeg']       // фото страницы блокнота
}
```

Чтобы добавить новую запись — скопировать любую соседнюю целиком (от `{` до `},`),
вставить рядом и поменять текст. Главное: у каждой записи свой `id`,
и `section` должен совпадать с одним из разделов в списке `sections` выше в файле.

Чтобы добавить новый раздел — дописать строку в `sections`, указав `group`
(`ogorod` или `kuhnya`), значок-эмодзи и название.

**После правки кода** (не данных) надо поднять номер версии в `index.html`
у `styles.css?v=`, `data/data.js?v=` и `app.js?v=` — иначе браузер покажет старую копию.

## Фотографии

Все 78 страниц блокнота лежат в папке `photos/` под именами из телефона
(`IMG_2447.jpeg` … `IMG_2531.jpeg`) и привязаны к своим записям через поле `photos`.
Новые фото кладутся туда же и вписываются в `photos` нужной записи. На странице они показываются
маленькими картинками, по клику открываются во весь экран.

## Пометки о неразборчивом почерке

Там, где в блокноте текст читается неуверенно, стоит `notes` с пометкой.
Такие места намеренно не додуманы — лучше свериться с фотографией страницы.

## Проверить целостность данных

```bash
node -e "global.window={};require('./data/data.js');const D=window.DATA;const ids=D.cards.map(c=>c.id);console.log('записей:',D.cards.length,'| дубли id:',ids.filter((x,i)=>ids.indexOf(x)!==i),'| чужие разделы:',D.cards.filter(c=>!D.sections.some(s=>s.id===c.section)).map(c=>c.id))"
```

78 страниц блокнота, сфотографированных на телефон (IMG_2447 — IMG_2531).
